▶ Chạy bằng lệnh (CLI)

Entry point: pipeline/batch_manager/batch-production-main.py — đọc mọi thứ (ảnh nền, LoRA, ComfyUI host, defect_distribution) từ file --config <yaml>. Đọc defect_distribution để dựng job list → sinh ảnh vào paths.output_base_dir. Chạy từ thư mục pipeline/ với venv của nó.
① Chạy pilot (nhanh) với config mặc định--pilot
Sinh 1 ảnh / mỗi defect có tỉ lệ >0 trong config — kiểm tra nhanh pipeline chạy được.
cd "/home/sontn/Projects/The Data Mint/pipeline"
source .venv/bin/activate
python batch_manager/batch-production-main.py \
  --config config/batch-config.yaml --pilot
② Sinh N ảnh 1 loại khuyết tật (config tạm)defect_distribution = {undercut: 1.0}
Clone config, ép chỉ 1 defect + số lượng + output riêng, rồi trỏ --config vào file tạm. Ví dụ: 100 ảnh undercut.
# tạo config tạm
python - <<'PY'
import yaml, os
cfg = yaml.safe_load(open('config/batch-config.yaml'))
cfg['generation']['total_images'] = 100
cfg['generation']['defect_distribution'] = {'undercut': 1.0}
base = '/home/sontn/Projects/The Data Mint/output/test-undercut'
cfg['paths']['output_base_dir'] = base
cfg['paths']['checkpoint_dir'] = base + '/_ckpt'
cfg['paths']['logs_dir']       = base + '/_logs'
os.makedirs('config/_generated', exist_ok=True)
yaml.safe_dump(cfg, open('config/_generated/undercut-100.yaml','w'), allow_unicode=True)
PY
# chạy
python batch_manager/batch-production-main.py \
  --config config/_generated/undercut-100.yaml
③ Batch dài chạy nền qua systemd-runbền — không bị kill
Job dài (hàng trăm ảnh) nên chạy như systemd transient unit để tách khỏi terminal — không chết khi đóng shell. Theo dõi bằng đếm PNG + journalctl.
systemd-run --user --unit=tdm-loswf500 \
  --working-directory="/home/sontn/Projects/The Data Mint/pipeline" \
  "/home/sontn/Projects/The Data Mint/pipeline/.venv/bin/python" \
  batch_manager/batch-production-main.py \
  --config config/_generated/loswf-500.yaml

# theo dõi
journalctl --user -u tdm-loswf500.service -f
ls output/test-loswf-500/*/*.png | grep -v mask | wc -l   # đếm ảnh
systemctl --user is-active tdm-loswf500.service            # còn chạy?

# xong thì dọn unit
systemctl --user reset-failed tdm-loswf500.service
⚠ Tùy chọn CLI: --config <path> (bắt buộc) · --pilot (1 ảnh/defect) · --resume (tiếp tục từ checkpoint không hỏi). ComfyUI server phải sống tại host trong config (mặc định 10.86.201.250:8188) trước khi chạy.
